# Contributing to Page Foundry

Thank you for helping authors publish from portable source material.

Contributions are welcome: bug reports, neutral examples, documentation and
focused improvements to the authoring and publishing workflows. Follow these
standards so authors can trust their source files and private designs.

## Principles

- Preserve the author's Markdown as the source of truth.
- Keep publishing deterministic, inspectable, and local by default.
- Do not add telemetry or transmit manuscript content.
- Keep private template packs and proprietary assets outside the repository.
- Use neutral, invented text in tests and examples.
- Make platform and output limitations explicit.

## Changes

Open an issue before substantial product or architecture work. Keep pull
requests focused and include tests proportional to the changed behaviour.
Document any new setup step, preset field, output limitation, or privacy
capability in the same change.

Generated PDF, EPUB, and DOCX fixtures must be checked both structurally and by
rendering representative pages for visual review.
