# Security Policy

## Supported versions

Security fixes target the latest release and current development on main. Report
the exact affected version or commit; older releases and individual betas are
not maintained independently. Install the corrected release when available, or
use BRAT to test a corrected beta.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting for this repository. Include the affected version or
commit, reproduction steps, expected impact, and any suggested mitigation.

Please do not include a real manuscript, private template pack, credential, or
other personal material in a report. Use the smallest neutral reproduction.

## Security boundaries

Page Foundry treats manuscripts and templates as sensitive local content. The
project must not introduce telemetry, automatic uploads, remote manuscript
processing, dependency self-installation, or arbitrary template-provided shell
commands.
