# 0.1.0-beta.2

Public beta testing through BRAT; no GitHub access token required. This is not a
stable release or an Obsidian community-directory submission.

Install `grobmeier/page-foundry` through BRAT and track latest or select
`0.1.0-beta.2`. Follow
[BRAT setup](https://github.com/grobmeier/page-foundry/blob/main/docs/testing/brat.md)
and the
[authoring checklist](https://github.com/grobmeier/page-foundry/blob/main/docs/testing/authoring-templates.md).

Changes from beta.1:

- Patched the development-only Moment dependency to 2.31.0; the full npm audit
  reports zero known vulnerabilities at preparation time.
- Added public BRAT instructions, clarified local configuration privacy, and
  configured weekly npm dependency-update proposals.
- Reviewed Git history, tracked source, previous beta assets and GitHub release
  content before public visibility. No secrets or private design material were
  detected. This is a point-in-time audit, not a security certification.

126 tests, format/type checks and the production build pass. Release assets
include licence texts and checksums; local private templates are not packaged.
Physical mobile/performance/sharing, retailer proof and richer private design
controls remain separate acceptance work. The compiler/font bundle is about 16
MB. Source notes remain authoritative; publishing does not rewrite them.
