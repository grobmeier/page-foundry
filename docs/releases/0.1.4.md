# Page Foundry 0.1.4

Includes the community-scorecard corrections described in [0.1.3](0.1.3.md):
validated metadata, searchable settings, restricted offline runtimes, exact
build packaging and attested release assets. Offline PDF and the Obsidian 1.8.7
minimum are unchanged.

The 0.1.3 source tag did not start a GitHub release workflow and has no
published release assets. It is retained unchanged. This version adds a tag-only
manual workflow trigger so a missed tag event can be recovered without moving a
tag.

The source lint, formatting, 192 tests, types, production build and real PDF
export checks pass. Physical mobile, accessibility and retailer acceptance
remain separate gates. Intentional YAML base64, clipboard-write and embedded
WASM disclosures remain; unavailable scans are controlled by the review service.
The offline bundle's 5 MB Sync Standard limit is retained for this patch and
tracked in [#39](https://github.com/grobmeier/page-foundry/issues/39).

Update, save open edits, reload Obsidian and confirm version 0.1.4. Writing,
private template packs and installed settings are not replaced.
