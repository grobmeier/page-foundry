# 0.1.0-beta.5

Reusable local book designs, edited through **Manage book designs** rather than
handwritten JSON. PDF designs now offer title/subtitle/imprint/contents pages,
chapter styles and rules, paragraph controls, running headers, page numbers and
paperback defaults. Contents entries link to their final pages.

**New design**, **Edit** and **Duplicate design** preserve existing presets.
Version-1 packs remain readable; adding book controls defaults to **Save a
copy** because older plugin versions cannot read version 2. **Create proof**
renders the active book with unsaved changes without saving the pack or
selecting the draft for the book. Publish remembers a successfully selected
saved design as before.

Book **Edit document details** adds optional subtitle and readable multiline
imprint. PDF-only controls do not change EPUB/DOCX. No raw template code, custom
fonts, imported ornaments or extra rendering dependencies are added. Real
private packs, templates and proof files stay outside release assets.

147 tests, formatting/type checks and build pass. Neutral desktop tests cover
draft proof, upgrade copy, save/duplicate and remembered Publish. Neutral
50-chapter print and ordinary PDFs exercise multi-page contents, numbering,
right-hand starts and blank pages; representative pages pass visual checks.
Physical mobile and retailer/print acceptance remain separate.

[Make your own book design](https://github.com/grobmeier/page-foundry/blob/main/docs/book-designs.md).
