# 0.1.0-beta.4

The simpler authoring/publishing workflow from beta.3, with an older-letter
compatibility correction. Install/update `grobmeier/page-foundry` through BRAT,
tracking latest or selecting `0.1.0-beta.4`.

Saving document details now preserves intentionally blank legacy greeting,
closing and signature properties. Updating old sender/recipient blocks keeps
their default sign-off/signature until you explicitly move that content into the
writing. New body-only letters still omit empty optional properties.

135 tests, formatting/type checks and the production build pass. The beta.3
native workflow/PDF checks remain applicable; the correction has focused
regression coverage. See
[Start here](https://github.com/grobmeier/page-foundry/blob/main/docs/start-here.md)
and the
[beta.3 workflow notes](https://github.com/grobmeier/page-foundry/blob/main/docs/releases/0.1.0-beta.3.md).
Physical mobile, retailer/print proof and richer private designs remain separate
acceptance work. Private vault content is not included in release assets.
