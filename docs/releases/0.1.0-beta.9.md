# Page Foundry 0.1.0-beta.9

A release candidate for the first Page Foundry release, with corrected PDF
paragraphs and line breaks, clearer setup and a tracked design roadmap.

## PDF fixes

- Custom book designs keep normal line separation between consecutive
  paragraphs. **Extra paragraph spacing** adds only the requested additional
  gap; zero no longer collapses the paragraph boundary. The fix applies to Book
  PDF and measured paperback layouts.
- Markdown hard line breaks produce real line breaks instead of printing
  internal formatting text. Existing writing and private design files do not
  need conversion. Regenerate affected beta.8 PDFs; existing exports are not
  rewritten automatically.

## Installation and your own designs

The README describes current author workflows and rendering technologies, with
neutral screenshots. Installation/update instructions explain release files and
BRAT's beta channel. The private-template walkthrough separates Markdown
starters from output designs and shows how to create, proof, save and reuse a
local book design without editing JSON.

PDF still uses bundled Libertinus Serif. Imported fonts, ornaments, drop caps
and more flexible page treatments are future work, not features of this beta.
The [roadmap](https://github.com/grobmeier/page-foundry/issues/37) links 31
follow-up issues with scope and acceptance criteria, including design controls,
content/interchange, print production, device/accessibility/reader validation
and release operations. Private designs and assets are not included in public
source, screenshots or release files.

## Verification and boundaries

182 tests, formatting, TypeScript checks and the production build pass. Compiled
ordinary/print book and Markdown edge-case proofs pass. A separate
PDF-coordinate regression checks 27 combinations of type size, line spacing,
extra paragraph gap and A4/US Letter/paperback layouts; representative raster
pages are inspected for readability. Licence texts and SHA-256 checksums are
included in the release assets.

Physical iPad/iPhone/Android offline rendering, memory and sharing, full
assistive-technology acceptance, fresh external reader/editor checks and
retailer/physical-print acceptance remain separately tracked. Desktop tests do
not establish those results. This is a prerelease, not a stable release or an
Obsidian community-directory listing.

## Update and try it

In BRAT, update `grobmeier/page-foundry` to **0.1.0-beta.9**. If your entry is
fixed to an older tag, select beta.9 explicitly. Save pending edits, fully
reload Obsidian, then confirm the installed version in Community plugins.

1. Publish a book using a custom design with zero extra paragraph spacing and
   several consecutive paragraphs. Check the resulting Book PDF and paperback
   proof for readable, evenly separated text.
2. Add a Markdown hard line break (two trailing spaces before a newline) to a
   neutral note. Publish PDF: expect a new line, not internal formatting text.
3. Open a book, use **Manage designs → Book designs**, change a design and
   **Create proof**. Save deliberately to a private pack, **Publish → Change
   layout**, then Publish again. Expect the saved design to be remembered and
   the book/chapter writing to remain unchanged.
4. Recheck tables, long rows, local images and literal code using neutral
   examples. Confirm the saved output path and available file actions.

Plugin updates preserve notes, private packs and settings; they do not replace
an existing example guide. Keep real manuscripts, fonts, artwork and templates
in your private vault outside the public checkout. Rendering remains on-device,
without Docker, Pandoc, native TeX, manuscript uploads or telemetry.
