# 0.1.0-beta.6

Markdown tables now export as formatted tables instead of pipe-delimited prose.
PDF supports aligned cells, inline formatting, local images, repeated headings
and rows that continue across pages. Wide tables become readable label/value
rows on narrow pages. Missing cells stay empty; excess cells and oversized
tables block publishing instead of silently losing content.

Images fit their containing cells, lists and page widths without stretching.
Wiki embeds accept a width/height box, such as `![[panel.png|300x200]]`; inside
a table, escape the pipe as `![[panel.png\|300x200]]`. Only local PNG/JPEG
images are supported. Remote images, SVG and HTML images remain blocked.

Fenced and indented code retains its literal text, indentation and line breaks.
PDF uses bundled monospace type and wraps long lines. Numbered PDF lists retain
their starting number. EPUB and DOCX retain tables and code too.

This beta also includes the previously staged custom book designs: **Manage book
designs** offers title/imprint/contents pages, chapter styles, running headers,
paperback defaults, duplication and unsaved proofs. Version-1 packs remain
readable; adding version-2 book controls defaults to saving a copy. Private
templates and assets stay outside the public repository and release.

154 tests, formatting/type checks and the production build pass. Neutral A4, US
Letter and 5×8 PDFs retain 90 table records, repeat headings, contain their
images and preserve an oversized row's ending. Representative pages were
visually inspected. Existing book-design pagination proofs also pass. Physical
mobile performance and retailer/print acceptance remain separate tests.

In BRAT, update `grobmeier/page-foundry` to **0.1.0-beta.6**, reload the plugin,
then follow the
[tables and PDF checklist](https://github.com/grobmeier/page-foundry/blob/main/docs/testing/local-images-and-mobile.md#tables-code-and-narrow-pdf-pages).
Keep original manuscript files backed up and test with neutral notes first.

Merged cells, rendered HTML tables, maths and diagram rendering are not
included. No Docker, Pandoc, rendering server or manuscript upload is needed.
