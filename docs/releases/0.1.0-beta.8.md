# 0.1.0-beta.8

Less setup for new notes, and a Publish review that keeps your choices.

- **Create new note** offers all five built-in starters directly: Letter,
  Submission letter, Manuscript, Book and Plain document, alongside registered
  private templates. Frequently used choices stay first.
- Enter a title and the filename follows. **File location (optional)** contains
  the filename, folder and missing-folder switch. Once you edit the filename,
  later title changes leave it alone. Book plans retain their `.book.md` marker;
  ordinary-note suggestions avoid accidentally becoming book plans.
- Cancelling **Change layout**, including **More layouts**, returns to the same
  Publish review. Choosing another layout retains your temporary filename,
  destination, language and compatible details. New fields come from the note;
  incompatible fields are dropped. Page and print defaults follow the chosen
  design. These changes do not rewrite the source note.
- Layout selection rechecks the source, resources and configured designs. A
  moved or unavailable note is refused instead of replacing the review.
- The example guide and author checklist cover these flows and the correctly
  named Broken ebook link example. External example maintenance now explicitly
  calls for a full Obsidian reload. A separate maintainer guide-refresh command
  recognises unchanged generated guides, verifies a private backup, and refuses
  edited or unknown guides. Installing this beta does not replace vault notes,
  settings, private templates or artwork.

181 tests, formatting/type checks and the production build pass. Native Obsidian
checks in a disposable neutral vault cover starter visibility,
title-derived/manual filenames, both layout-picker cancellation routes,
compatible-detail retention, actual DOCX output and all five guide links. All 24
neutral fixture files remained byte-identical after these checks. Physical
mobile, assistive-technology, EPUB reader and retailer/print acceptance remain
separate gates. This is a prerelease, not a stable/community-directory release.

## Update and try it

In BRAT, update `grobmeier/page-foundry` to **0.1.0-beta.8**. If your entry is
frozen to an older release, select beta.8 explicitly or switch to tracking
latest. Save pending edits, then fully reload Obsidian and confirm beta.8 in
Community plugins. Updating BRAT does not refresh an existing example guide.

Try the
[author test path](https://github.com/grobmeier/page-foundry/blob/0.1.0-beta.8/docs/testing/authoring-templates.md):
create a neutral letter, change its title, override its filename and change the
title again. Publish an example manuscript, edit export-only details, cancel
Change layout, then choose DOCX. Expect your compatible choices to survive and
the original writing to remain unchanged.

Private designs remain outside the public repository and release. Rendering
stays on-device, without Docker, Pandoc, a server or manuscript uploads.
