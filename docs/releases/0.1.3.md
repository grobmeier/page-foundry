# Page Foundry 0.1.3

Corrects the community-review source findings and release build mismatch while
retaining offline PDF export and the Obsidian 1.8.7 minimum.

- Validates YAML and stored history before field access, preserves explicit
  control-character/path rejection and uses runtime file-class checks.
- Adds searchable settings on Obsidian 1.13+, using the same controls and save
  handlers on older hosts. Clipboard writes use the modal's owning window;
  optional desktop file actions remain unavailable on mobile.
- Removes unused declarations, unnecessary assertions/escapes and deprecated
  Markdown node types. A repeatable zero-warning lint gate covers these rules.
- Restricts the PDF dependency adapters to local module/font bytes and static
  reviewed callbacks. Arbitrary JavaScript, optional remote/filesystem loaders
  and legacy DOCX string-code fallbacks are removed, not renamed or hidden.
- Builds licence notices into `main.js` before packaging, which now copies the
  exact build. Stable CI checks repeated builds, attests the three installed
  files and publishes only those files. Earlier release assets are unchanged.

192 tests, source lint, formatting, types and the production build pass. Real
book/table/image PDF exports and repeated browser-style DOCX exports are
included in verification. These checks do not certify physical mobile,
accessibility, reader interoperability or retailer/print acceptance.

Some disclosures are intentional or service-controlled: YAML binary-data base64
codecs, explicit Copy-report actions, the embedded WASM compiler and unavailable
scan services. The offline bundle remains above Sync Standard's 5 MB per-file
limit, as explicitly retained for this patch; size reduction is tracked in
[#39](https://github.com/grobmeier/page-foundry/issues/39). See
[the review and provenance explanation](../architecture/review-hardening.md).
GitHub attestations establish provenance, not malware safety, and the community
review of this exact release must still be checked after publication.

Update, save open edits, reload Obsidian and confirm version 0.1.3. Private
writing, template packs, designs and installed settings are not replaced.
