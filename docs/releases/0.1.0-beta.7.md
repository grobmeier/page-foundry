# 0.1.0-beta.7

A simpler author workflow, with safe document-type changes.

- **Edit document details → Document type** switches individual notes between
  Plain document, Letter, Submission letter and Manuscript. Fields change in
  place; entered values survive switching. Only **Save details** applies
  changes.
- Saving a type change preserves writing and unedited properties, inserts no
  starter text, and resets that note's remembered output design. **Publish**
  then opens the new type's default. Books keep their separate reading-order
  editor.
- Seven everyday commands replace fifteen. **Manage designs** groups Book
  designs and Document designs. Migration-only commands and duplicate
  Publish/help commands are removed; existing files remain supported without
  conversion.
- Publish shows the document type and distinguishes temporary export details
  from saved note details, with a direct route to the persistent form.
- Current help and the neutral example generator follow one author test path.
  Obsolete installation instructions are removed. Updating the plugin does not
  replace your notes, settings, private templates or artwork.

171 tests, formatting/type checks and the production build pass. Native Obsidian
checks in a disposable neutral vault cover keyboard Cancel and Save, type →
Publish defaults, saved-details navigation and the separate book-order editor.
Physical mobile, assistive-technology, EPUB reader and retailer/print acceptance
remain separate checks. This is a prerelease, not a stable/community-directory
release.

In BRAT, update `grobmeier/page-foundry` to **0.1.0-beta.7**, then reload
Obsidian or disable/re-enable Page Foundry. Confirm the version in Community
plugins. If a frozen version is selected, change it to beta.7 or track latest.

Try
[the short author test path](https://github.com/grobmeier/page-foundry/blob/0.1.0-beta.7/docs/testing/authoring-templates.md):
change a neutral letter to Manuscript, Cancel first, then save and Publish.
Writing and addresses must remain intact, and General manuscript PDF should open
automatically. Change it back and confirm Letter PDF returns.

Private designs remain outside the public repository and release. Rendering
stays on-device, without Docker, Pandoc, a server or manuscript uploads.
