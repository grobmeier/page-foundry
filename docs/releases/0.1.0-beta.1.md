# 0.1.0-beta.1

First private BRAT testing release. This is not a stable release or a public
Obsidian directory submission. The repository remains private.

## Try first

- Create new note: prepare an independent letter/manuscript/book with saved
  properties, without exporting or changing the previously active note.
- Edit document details: persist letter names/addresses and readable book order.
- Publish: render PDF, EPUB or DOCX locally; no Docker, Pandoc or native TeX.
- Save a neutral custom Markdown note template and edit a local output preset.

Use
[private BRAT setup](https://github.com/grobmeier/page-foundry/blob/main/docs/testing/private-brat.md)
and the
[authoring test plan](https://github.com/grobmeier/page-foundry/blob/main/docs/testing/authoring-templates.md).
Install `grobmeier/page-foundry`, selecting `0.1.0-beta.1`. Private downloads
require a dedicated fine-grained token with Contents read access only to this
repository. Do not paste the token into an issue, screenshot or chat.

## Validation and limits

126 automated tests, format/type checks and the production build pass.
Previously tested native desktop authoring/export flows are unchanged by this
packaging release. The assets include licence notices and SHA-256 checksums.
Only neutral engine material is included; private designs are externally
configured, never embedded in release assets.

Physical iPad/iPhone/Android memory, offline generation and system sharing still
need testing. Paperback retailer/physical-print acceptance and richer custom
design controls are separate. EPUBCheck was not rerun for this release;
structural EPUB regression tests pass. Known moderate development-tooling
Moment/Obsidian advisories remain tracked; no production security certification
is claimed. The compiler/font bundle is approximately 16 MB, so first install
and first PDF generation may take longer on mobile.
