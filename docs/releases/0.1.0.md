# Page Foundry 0.1.0

Prepared release notes. This version has not been published; beta downloads
remain available through BRAT. Complete the maintainer release checklist before
using these notes for a stable release.

Page Foundry turns Obsidian writing into letters, submission manuscripts,
ordered books and paperback proofs. Keep writing in Markdown, then publish a
separate PDF, EPUB or editable Word document.

## Write, organise, publish

- Create a Letter, Submission letter, Manuscript, Book or Plain document with
  its properties ready. Save your own Markdown starters for reuse.
- Edit readable author/address details and change an individual note's type
  without replacing its writing.
- Build a book from explicitly ordered opening pages, parts, chapters, scenes
  and closing pages. Chapter notes remain unchanged.
- Choose and reuse an output layout. Publication reviews required details and
  referenced resources, remembers successful layouts and preserves compatible
  temporary choices when changing designs.
- Save to a configurable vault folder. See the actual saved path and use
  supported desktop open/reveal or system sharing actions.

## Your own appearance, your own storage

Use form-based document and book design editors for typography, opening pages,
chapter treatments and running headers. Create an unsaved proof, then save the
design in a local JSON pack. Private note templates and design packs stay in
your own vault, outside the public plugin repository.

Paperback proofs support 5 × 8, 5.5 × 8.5 and 6 × 9 inch no-bleed black-ink
interiors with measured gutters and chapter-start options. Covers, spines and
retailer approval remain separate production steps.

## Local publishing

PDF uses an embedded Typst WebAssembly compiler and bundled fonts. EPUB 3 uses
semantic XHTML/CSS and ZIP packaging; DOCX uses Open XML. Headings, lists,
quotations, links, pipe tables, literal code and referenced PNG/JPEG images are
supported. Rendering stays on-device: no Docker, Pandoc, TeX installation,
rendering account, manuscript uploads or telemetry.

This release includes fixes for overlapping consecutive paragraphs in custom
book PDFs and incorrect Markdown hard line breaks. Regenerate affected beta.8
PDFs after installing a build containing the fixes.

## Install and keep testing

Requires Obsidian 1.8.7 or newer. Follow
[installation and updates](../install.md). BRAT remains the beta channel: add
`grobmeier/page-foundry` to try beta builds, or select a fixed release tag.
Plugin updates preserve existing notes and private designs; they do not replace
an example vault or rewrite old exports.

See the [everyday guide](../start-here.md),
[private-template walkthrough](../custom-templates.md) and
[supported content and limits](../supported-content.md). PDF page design is
separate from EPUB/DOCX layout; custom fonts, ornaments and executable template
imports are not supported. Physical mobile, assistive-technology, reader and
print checks must be reported from actual acceptance, not inferred from local
builds.
