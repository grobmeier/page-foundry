# Page Foundry 0.1.1

Removes the legacy script-element scheduling fallbacks that blocked the
automated Obsidian community review of 0.1.0. This is a dependency/runtime
packaging fix; your notes and saved designs do not need conversion.

DOCX uses the same pinned JSZip version as before, built from modular source
with native Promise and a yielding, function-only timer scheduler. Obsolete
script/string-code fallback modules and unused Node-stream support are omitted.
The build checks the upstream distribution and rejects reintroduced script
creation. Dependencies and licence notices remain documented; no published 0.1.0
assets are replaced. See [the adaptation](../architecture/zip-runtime.md).

185 tests, formatting, types and the production build pass, including repeated
browser-style DOCX book/table/image creation, scheduling/cancellation and
fail-closed build checks. PDF and EPUB behaviour remains unchanged; the normal
compiled PDF regression checks are retained.

The embedded PDF compiler still makes the plugin larger than the Obsidian Sync
Standard 5 MB file limit reported by the directory. That packaging limitation is
tracked in [#39](https://github.com/grobmeier/page-foundry/issues/39), not
claimed fixed here. Artifact attestations and physical mobile, accessibility,
reader/editor and print acceptance also remain separate work. A successful
GitHub release is not by itself community-directory approval.

Install the stable release through the available
[installation route](../install.md); BRAT remains available for beta testing.
Save open edits, reload Obsidian after updating and confirm version 0.1.1.
Private templates, fonts, artwork and writing stay outside the public release.
