# Page Foundry 0.1.5

This patch removes unnecessary YAML binary-data conversion without changing the
offline PDF compiler, embedded fonts or plugin packaging.

- Existing `!!binary` custom properties are preserved as opaque tagged text when
  editing notes or book plans. They are not decoded or treated as ordinary
  title, author or other text metadata.
- Comments, aliases, dates, custom tags and ordinary document properties retain
  their existing handling. Malformed binary-tagged text remains an error, and
  document details require a YAML mapping rather than a scalar root.
- Version- and source-hash guards require review before adapting an updated YAML
  dependency. The production build also rejects reintroduced browser
  `atob`/`btoa` calls.

All 200 tests pass, including Copy-button behaviour. Offline PDF exports match
the previous baseline across 34 PDFs / 249 pages; 27 paragraph-layout checks and
visual table/image and book-title checks pass. The verified release workflow
checks repeatable build output and attests the three installed plugin assets.
Physical mobile, accessibility and retailer acceptance remain separate gates.

Copy buttons remain available. Embedded PDF assets still use encoded binary data
and the existing local decoder; this is not a base64-free runtime. The offline
bundle still exceeds the Sync Standard 5 MB per-file limit, tracked in
[#39](https://github.com/grobmeier/page-foundry/issues/39). Community scan
availability and disclosures are controlled by its review service.

Update through Obsidian's community-plugin updater or BRAT, save open edits,
then reload Obsidian and confirm version 0.1.5. Notes, private template packs
and installed settings are not replaced. The minimum Obsidian version remains
1.8.7.
