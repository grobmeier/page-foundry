# Page Foundry 0.1.2

Removes a regular-expression lookbehind from the book-plan editor extension.
Older iOS engines cannot parse lookbehind, which caused a separate blocking
finding in the community review of 0.1.1. Line endings and source-relative
comment ranges are preserved without that syntax.

Regression tests cover LF and CRLF, blank lines, Unicode text, fenced examples
and files without a final newline. All 187 tests, formatting, types and the
production build pass. This is a compatibility correction, not a claim of
completed physical-device acceptance.

Includes the 0.1.1 DOCX/JSZip scheduler fix. Previous release files remain
unchanged. No note or private design conversion is required.

The plugin remains larger than the Obsidian Sync Standard 5 MB file limit; that
separate packaging limitation is tracked in
[#39](https://github.com/grobmeier/page-foundry/issues/39). Other community
recommendations and physical mobile, accessibility, reader and print checks
remain separate work. GitHub publication does not by itself mean the community
review is approved.

Save open edits, update, reload Obsidian and confirm version 0.1.2. BRAT remains
available for prereleases. Private writing, designs and assets are not shipped.
