# README screenshots

These are unedited native Obsidian screenshots captured with the published Page
Foundry `0.1.0-beta.8` plugin on 19 October 2026. All writing, names and designs
come from the public neutral example generator in a separate demo vault. No
owner vault, private template, personal path or credential is shown.

- `book-pdf.jpg`: the Markdown reading-order plan beside its generated PDF,
  using the standard Plain document layout. The PDF is open at the first
  chapter; this is Obsidian's PDF viewer, not a live Page Foundry preview.
- `create-note.jpg`: the Manuscript starter with a title-derived filename and
  optional file-location controls. The form was cancelled without saving.

The native screenshots are JPEG files at their original capture dimensions. They
were visually inspected before inclusion. The neutral custom-book spacing defect
discovered during capture is recorded in
[supported content](../supported-content.md#beta8-custom-book-spacing-issue);
the book overview deliberately identifies the standard layout it demonstrates.
