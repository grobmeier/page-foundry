# Try the author workflow

Start with [the everyday guide](../start-here.md), then follow the
[author workflow acceptance path](authoring-templates.md).

Create prepares a new Markdown note. Edit document details saves properties and
changes individual-note type. Publish makes a separate PDF, EPUB or DOCX using a
design. Books use ordered chapter plans. The test vault has one Start here note
and a neutral Examples tree; it does not need separate report notes.
